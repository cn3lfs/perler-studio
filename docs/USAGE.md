# 使用说明

## 直接运行

下载整个仓库 ZIP 并解压，在电脑浏览器打开根目录 `index.html`。请保留 `source` 目录，不要只下载 index.html。没有 npm 安装步骤。默认不需要 API Key，也不联网；只有勾选「AI 辅助」时才需要。

## 从图片到图纸

1. 在「底板与豆径」里选底板规格和豆子直径，需要更大的作品就增加横向 / 纵向拼板数量，然后点击「应用尺寸」。
2. 把图片拖进页面，或点击虚线框选择，或直接 Ctrl+V 粘贴。支持 PNG / JPG / WebP，单张不超过 20 MB。
3. 在弹出的裁剪框里拖出要做成拼豆的区域。「按画板比例」会按当前画板的宽高比居中取最大区域。点击「应用并生成图纸」。
4. 不满意可以调整左侧选项后再点「生成拼豆图纸」，或用画笔逐格修改。
5. 点击「高清 PNG」导出。

### 底板怎么选

| 底板 | 配套豆径 | 单块边长 | 单块成品约 |
| --- | --- | --- | --- |
| 52×52 小豆板 | 2.6 mm | 约 14.5 cm | 13.5 × 13.5 cm |
| 29×29 标准板 | 5 mm | 约 14.5 cm | 14.5 × 14.5 cm |

104 钉的大板相当于 52 板横 2 × 纵 2。列数和行数也可以直接填 5–156 的任意整数（例如 52×40），此时所需底板块数按整块向上取整。选「自定义格数」则不画底板分界线。

### 生成选项

| 选项 | 作用 |
| --- | --- |
| 图片放置 | 完整放入（四周可能留空）、铺满裁切、拉伸填满 |
| 最多用色 | 限制豆子颜色数。颜色越少越好买、越好拼，但过渡更生硬 |
| 取色方式 | 卡通 / 像素图取每格主色，边缘清晰；照片取平均色，过渡柔和 |
| 杂点清理 | 轻度：把颜色相近的孤立单颗并入周围，高反差的单颗保留。强力：孤立单颗一律并入周围，适合平涂卡通，会抹掉单颗高光 |
| 背景处理 | 保留原样；统一成一个色号（从四边向内，把与边缘相近的格子都换成同一种豆）；留空不放豆 |
| 背景容差 | 多大的色差仍算背景。背景没去干净就调大，吃进了主体就调小 |
| 背景色号 | 「统一」时用哪种豆铺背景；留空则自动取最接近的 |
| 背景色只用于背景 | 勾选后主体内部不会再用背景那种豆，避免白色主体里混进米色 |
| 去掉交界处的混色 | 两个色块交界的格子会取到混合色；勾选后把它归到其中一边。仅卡通取色时生效 |
| 限定色号 | 只用列出的豆，用逗号或空格分隔；填写后「最多用色」不再生效 |
| 抖动过渡 | 用两种豆交错模拟中间色，适合照片渐变；开启后不做杂点清理 |

透明豆 H1 不参与自动匹配，需要时可以手动选用。「统一背景」时背景另占一个色号，不计入「最多用色」。

### 原图是 AI 画的“拼豆图纸”怎么办

AI 生成的拼豆效果图通常网格是假的：标注的格数和画出来的线对不上，色块也不贴格线。不要照着它的格子数，把它当普通图片处理：只框选图案区域，按想要的成品大小选底板，文字多就用更大的格数；取色选「卡通」，背景选「统一成一个色号」，清理选「强力」，再限定十种左右的色号，或者勾选 AI 辅助让它来挑。

### AI 辅助（可选）

1. 勾选「AI 辅助选色与参数」，填入 DeepSeek 的 API Key。Base URL 和模型已经填好，一般不用改。
2. 点击「生成拼豆图纸」。默认的「仔细思考」需要等 20–60 秒。
3. AI 的判断会显示在下方，并自动填入取色方式、背景处理、背景色号、清理强度和限定色号。不满意就改掉对应选项，取消勾选 AI 后再生成一次，这样不会被 AI 重新覆盖。

发给接口的只有裁剪区缩略图（最长边 512 px）和候选色号列表。Key 只存在本浏览器，不进工程文件。失败时会说明原因（Key 无效、余额不足、模型不支持图片等），并按当前本地选项照常生成。

## 图纸怎么看

- 灰色小数字是每颗豆的列号、行号；蓝色数字标在每 5 格的边界上。
- 蓝线每 5 格一条，线间有 4 条细线。列数或行数不是 5 的倍数时，最后一组不足 5 格（52 格时最后一组是 2 格）。
- 红色粗线是相邻两块底板的分界。
- 灰色小点表示留空不放豆；白色色号要放白豆。
- 图纸下方是标题、规格、每个色号的颗数和 50 mm 校准尺。

## 导出

PNG、SVG、逐格 CSV 和用量 CSV 均由同一份格子数据生成，原图不会进入导出结果。

- **高清 PNG**：整张图纸。
- **按底板分张导出 PNG**：多块底板时每块底板一张，文件名带「board-行-列」，行列编号沿用整图坐标，每张只统计该底板的用量。
- **实尺 SVG**：按所选豆径写入毫米尺寸。打印请选 100% / 实际大小，先核对 50 mm 标尺。
- **纯图 PNG**：只有色块，没有网格和文字。

未连通时默认阻止正式图纸导出；取消「正式图纸要求全部连通」可以导出检查稿。移除背景后图案常会分成几块，可用「补连接」处理。

## 校验示例

上方「载入校验示例」会把确认过的 50×50、5 mm 工程直接载入，不进行图片取样。示例共 2500 颗、12 色；H12 背景必须摆豆。它是原主题的像素适配版，不是参考图无损复刻。

## 生成便携单文件

运行 `python scripts/build.py`。输出 `dist/perler-studio.html` 和 `dist/aipin_verified_project.json`。单文件 HTML 可以单独复制，仍然离线运行。

## 验证

- `python scripts/verify.py`：检查色库、50×50 示例、用量及四向连通。这是静态和数据检查，不冒充浏览器测试。
- `node scripts/test_quantize.js`：用论文公布的参考数据核对 CIEDE2000 色差，并检查限色、去杂点和抖动。
- `node scripts/test_ai.js`：检查 AI 请求的组装和对回复的校验，全程不联网。
- 网页右侧另有「查看网格自检报告」。

## 注意事项

自动采样不能识别复杂汉字，仍需检查字形。MARD 色值是社区参考值；检查几何连通不能代替实体熨烫试验。156×156 的大图约 2.4 万颗，编辑时会比小图慢。不要把私人照片或令牌提交进公开仓库。

本次上传没有启用 GitHub Pages。GitHub 文件浏览页显示源码，不是程序的运行页面。
