# 使用说明

## 直接运行

下载整个仓库 ZIP 并解压，在电脑浏览器打开根目录 `index.html`。请保留 `source` 目录，不要只下载 index.html。没有 npm 安装步骤，也不需要 API Key。

上方「载入校验示例」会把最后确认的 50×50 工程直接载入，不进行图片取样。示例共 2500 颗、12 色；H12 背景必须摆豆。它是原主题的像素适配版，不是参考图无损复刻。

日常操作：设置格数与豆规格 → 更换图片并裁剪 → 自动生成初稿或逐格画 → 检查连通 → 导出。保存工程 JSON 可以跨设备继续编辑。

## 生成便携单文件

运行 `python scripts/build.py`。输出 `dist/perler-studio.html` 和 `dist/aipin_verified_project.json`。单文件 HTML 可以单独复制，仍然离线运行。

## 验证

运行 `python scripts/verify.py`，检查色库、50×50 示例、用量及四向连通。该脚本是静态和数据检查，不冒充浏览器测试。网页右侧另有「查看网格自检报告」。

## 网格与实际尺寸

默认每格 5mm。50×50 格的网格名义尺寸为 250×250mm。每 5 格一条蓝线，线间有 4 条内部细线。蓝色数字是边界计数；灰色小数字是每颗豆的行列编号。空格不放豆，白色色号要放白豆。

## 导出

PNG、SVG、逐格 CSV 和用量 CSV 均由同一份格子数据生成，参考图层不会导出。SVG 带毫米尺寸，打印请选择 100%/实际大小，先检查 50mm 标尺。未连通时默认阻止正式图纸导出，可取消限制导出检查稿。

## 注意事项

原始大参考截图没有嵌入此源码版；内置缩略预览由已校验的格子数据生成。你仍可以导入自己的 PNG/JPG/WebP 图片。

自动采样不能识别复杂汉字，仍需检查字形。MARD 色值是社区参考值；检查几何连通不能代替实体熨烫试验。不要把私人照片或令牌提交进公开仓库。

本次上传没有启用 GitHub Pages。GitHub 文件浏览页显示源码，不是程序的运行页面。
