底板与豆径

国内最常见的是 2.6 mm 小豆配 52×52 底板，其次是 5 mm 标准豆配 29×29 方板，两种底板边长都约 14.5 cm，可以拼接。选「横向 / 纵向拼板」会按整块底板放大画板；也可以直接填 5–156 的任意列数和行数。图纸上每 5 格一条蓝线（末尾不足 5 格时按实际格数），红线是相邻底板的分界。成品尺寸按「豆径 × 格数」估算，实际熨烫后会略有出入。

图片怎么变成色号

程序把裁剪区按画板格数切分，每格取一个颜色，再用 CIEDE2000 色差在 MARD 221 色里找最接近的豆子。「卡通 / 像素图」取每格的主色，边缘清晰，也能避开旧图自带的细网格；「照片 / 写实」取平均色，过渡更柔和。「最多用色」会把用量少、且有相近替代色的豆子并掉；「合并孤立杂点」只合并颜色相近的单颗，高反差的单颗（如眼睛高光）会保留；「抖动」适合照片渐变。默认保持原图比例；格数越少细节越少，中文字和五官请放大逐格修正，程序没有 OCR。

叠加原图只是辅助描绘，永远不会写进导出的图纸。每个格子只保存一个色号。

背景、杂点和限定色号

浅色底带纸纹或网格时，把「背景处理」设为「统一成一个色号」，背景会变成同一种豆；想做镂空就选「留空」。平涂卡通用「强力」清理；「去掉交界处的混色」能避免黑白之间冒出灰色。知道该用哪几种豆时，直接填进「限定色号」。

AI 辅助（可选）

默认关闭，此时程序不发任何网络请求。勾选并填入 DeepSeek 的 API Key 后，生成时会把裁剪区缩略图和候选色号发给模型，由它挑选保留的色号、判断背景和清理强度，结果填回面板，逐格配色仍在本机完成。Key 只存在本浏览器。AI 的建议不保证更好，生成后仍需检查；失败时按本地选项照常生成。

编辑与检查

B 画笔、E 橡皮、F 同色区填充、I 吸取格色、V 拖动画布；Ctrl/Cmd+Z 撤销，Ctrl/Cmd+Shift+Z 重做。手机可使用工具按钮和缩放滑块。需要滚动页面时从画布外拖动。

分离区域采用上下左右四邻接检查，斜角不算接触。“补连接”会用当前色新增路径；可以选择 1 或 2 格宽并撤销。它只保证数字网格的连通，不代表熨烫后的物理强度。

色号不是随意编号

内置 221 个 MARD 色号。RGB 值来自 craft-color-codes by MakeBead，按 CC BY 4.0 使用；原数据标注为 community，不是厂商官方校准。这里仅取 code/hex 字段，A01 与 A1 统一为 A1。可逐色校正或导入自己的 JSON 色库；原参考图里的错误色号不会被读取。

导出与尺寸

PNG、SVG、逐格 CSV、用量清单都从同一份二维矩阵生成。PNG 适合看图，实尺 SVG 的格距按所选豆径写入。例如 52×52、2.6 mm 的网格区域是 135.2×135.2 mm，不含坐标和图例。多块底板时可用「按底板分张导出」，每块底板一张图，行列编号沿用整图坐标。打印请用实际尺寸，并用导出图底部的 50 mm 校准尺检查。截图大小、屏幕缩放和 PNG 默认打印缩放都不代表实际尺寸。

本地保存

不使用 AI 辅助时，图片仅在当前浏览器处理，不会上传。程序尝试在本地缓存格子（不缓存参考图），不同浏览器或文件打开方式可能禁止缓存。请使用“保存工程”下载 JSON，里面含矩阵、色库、参考图与裁剪参数。离线 HTML 需在浏览器中运行；部分手机文件预览器不会执行脚本，可使用电脑浏览器或将文件放到静态网站。

网格 / 导出前自检
