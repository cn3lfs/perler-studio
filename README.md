# 格序 · 拼豆图纸工作台

从逐格色号矩阵生成拼豆施工图，而不是给图片叠上不准确的网格。

## 使用

下载本仓库后，用浏览器打开 `index.html`。程序仅在本地处理图片，不需要 API Key。保存工程 JSON 可以在另一台电脑继续编辑。

默认 50×50 格、5mm 拼豆；每 5 格一条蓝色定位线。参考图只是填色参考，不会进入正式导出图。支持画笔、橡皮、填充、取色、撤销重做、MARD 221 色库、四向连通检查、PNG/SVG/CSV/JSON 导出。

## 注意

- 5mm 豆的 50×50 网格名义尺寸为 25×25cm，不是迷你钥匙扣尺寸。
- 相邻蓝线之间有 4 条内部细线，形成 5 个小格。
- 仅对角接触不算连接；几何连通不等于实体熨烫强度保证。
- 自动采样只是初稿，尤其需要检查复杂汉字和细小五官。
- MARD 221 RGB 为社区参考色值，不是厂商实测校准值；选豆以实体色卡为准。
- 示例是参考图的 50×50 像素适配版本，不是原图无损复刻。
- 请定期导出工程，不要只依赖浏览器缓存。
