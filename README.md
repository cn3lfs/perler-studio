# 格序 · 拼豆图纸工作台

给一张图片，选底板尺寸和豆子直径，得到一张能照着拼的拼豆图纸：每格一个 MARD 色号，带网格、坐标、底板分界线和用量清单。

图纸来自逐格色号矩阵，而不是给图片叠上不准确的网格。

## 三步出图

1. **选底板与豆径**：52×52 小豆板（2.6 mm 豆）、29×29 标准板（5 mm 豆）或自定义格数；可横向、纵向各拼 1–3 块底板。
2. **导入图片**：拖入、点击选择或 Ctrl+V 粘贴，框选要做的区域，点击「应用并生成图纸」。
3. **检查并导出**：高清 PNG（网格 + 色号 + 用量清单）、按底板分张的 PNG、实尺 SVG、逐格 CSV、用量 CSV。

下载本仓库后，用浏览器打开 `index.html` 即可，没有安装步骤。默认完全在本地处理，图片不上传，不需要 API Key。想让 AI 帮忙挑色号时再勾选「AI 辅助」，填一个 DeepSeek 的 Key 即可（见下文）。

## 功能

- **底板**：列数、行数可以是 5–156 的任意整数；多块底板时图纸上用红线标出分界，并可每块底板单独导出一张图，行列编号沿用整图坐标。
- **豆径**：2.6 mm、5 mm、2.5 mm、10 mm；成品尺寸和实尺 SVG 按所选豆径计算。
- **图片转色号**：按 CIEDE2000 色差在 MARD 221 色中匹配，自动跳过透明豆 H1。
  - 取色方式：卡通 / 像素图取每格主色，照片取每格平均色。
  - 最多用色：8 / 12 / 16 / 24 / 32 / 48 / 不限。超出时并掉“颗数少且有相近替代色”的颜色。
  - 杂点清理：轻度只合并颜色相近的孤立单颗；强力适合平涂卡通，孤立单颗一律并入周围。
  - 背景处理：保留、统一成一个色号（适合带纸纹或网格的浅色底）、留空不放豆。
  - 去掉色块交界处的混色，避免黑白之间冒出灰色、黑橙之间冒出棕色。
  - 限定色号：只用你指定的几种豆。
  - 可选抖动（照片渐变）。
- **AI 辅助（可选，默认关闭）**：见下一节。
- **编辑**：画笔、橡皮、填充、取色、撤销重做、逐色校色、导入导出色库。
- **检查**：四向连通检查、补连接、网格自检报告。
- **工程文件**：保存 / 打开 JSON，可在另一台电脑继续编辑。

## AI 辅助（可选）

不勾选时程序不发任何网络请求。勾选「AI 辅助选色与参数」并填入 API Key 后，每次生成会多一步：

1. 本机先做一遍不限色的匹配，得到候选色号列表。
2. 把裁剪区缩略图（最长边 512 px）和候选色号发给模型。
3. 模型只回答设置：保留哪些色号、背景怎么处理、清理强度、取色方式，以及原图的问题提示。
4. 这些设置填回面板，逐格配色仍由本机算法完成。你可以改掉任何一项再重新生成。

默认接口是 DeepSeek，只需要填 Key：

| 项 | 默认值 |
| --- | --- |
| Base URL | `https://api.deepseek.com` |
| 模型 | `deepseek-flash`（需支持图片输入） |
| 分析方式 | 仔细思考，约 20–60 秒；可改为快速，约 3 秒但容易漏色 |

也可以改成任何兼容 OpenAI `chat/completions`、支持图片输入和浏览器直连的接口。Key 只保存在本浏览器的 localStorage，不写入工程文件和导出文件；可随时点「清除已保存的 Key」。AI 请求失败时会提示原因，并按面板上的本地选项照常生成。

AI 给的是建议，不保证更好：它擅长把明暗渐变并成一个纯色、判断背景该不该留，但也可能漏掉小面积的颜色。生成后仍需检查。

## 注意

- 国内主流是 2.6 mm 小豆配 52×52 底板；5 mm 豆配 29×29 方板。两种底板边长都约 14.5 cm。
- 成品尺寸按“豆径 × 格数”估算（52 格 × 2.6 mm ≈ 13.5 cm），熨烫后会略有出入。
- 每 5 格一条蓝线；列数或行数不是 5 的倍数时，最后一组不足 5 格。
- MARD 221 的 RGB 是社区参考色值，不是厂商实测校准值；选豆以实体色卡为准。目前只内置 MARD 色号，没有其他品牌的色号对照。
- 自动转换不识别文字，格数越少细节越少；中文字和五官需要放大逐格修正。
- 仅对角接触不算连接；几何连通不等于实体熨烫强度保证。
- 请定期保存工程，不要只依赖浏览器缓存。
